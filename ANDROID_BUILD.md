# Koupl — Android packaging (Capacitor)

Koupl is a server-rendered TanStack Start app. The Android shell is a Capacitor
WebView that loads the deployed production build, so the web app stays the single
source of truth (all routes, direct refresh, Supabase auth and realtime all work
exactly as they do on the web).

| Item | Value |
| --- | --- |
| App name | Koupl |
| Application / package ID | `com.koupl.app` |
| Production URL loaded by the app | `https://koupl-connect-play.lovable.app` |
| min SDK / target SDK | 24 / 36 |
| Version | `versionCode 1`, `versionName "1.0"` (bump in `android/app/build.gradle`) |
| Permissions | `android.permission.INTERNET` only |

## Files added

- `capacitor.config.ts` — app id/name, production `server.url`, splash and keyboard config.
- `android/` — full native Android Studio project (generated by `npx cap add android`).
- `android-www/index.html` — offline fallback screen shown when the device is offline.
- `src/lib/koupl/native.ts` — Android-only runtime: status bar colour, splash hide,
  keyboard inset variable, hardware back button navigation (exits only at the home route).
- Original Koupl launcher icons (`mipmap-*`), adaptive icon, and splash images
  (`drawable-port-*` / `drawable-land-*`) generated from `src/assets/koupl-mark.png`.

## Changing the URL the app loads

```bash
KOUPL_APP_URL="https://your-domain.example" npx cap sync android
```

## Build a debug APK (phone testing)

```bash
# 1. install dependencies
npm install            # or: bun install

# 2. sync web config + plugins into the native project
npx cap sync android

# 3. open Android Studio (Build > Build Bundle(s)/APK(s) > Build APK(s))
npx cap open android

# …or from the command line:
cd android
./gradlew assembleDebug
# output: android/app/build/outputs/apk/debug/app-debug.apk
```

Install on a connected phone: `adb install -r android/app/build/outputs/apk/debug/app-debug.apk`

## Build a signed release APK / AAB (Play Store)

1. Create a keystore once (keep it private, never commit it):

```bash
keytool -genkey -v -keystore koupl-release.keystore -alias koupl \
  -keyalg RSA -keysize 2048 -validity 10000
```

2. Create `android/keystore.properties` (git-ignored) with your own values:

```properties
storeFile=/absolute/path/to/koupl-release.keystore
storePassword=YOUR_STORE_PASSWORD
keyAlias=koupl
keyPassword=YOUR_KEY_PASSWORD
```

3. In Android Studio: **Build > Generate Signed Bundle / APK**, pick *Android App
   Bundle* for Play Store or *APK* for direct install, choose the keystore above,
   and select the `release` build variant.

   Command line equivalent (after wiring the signing config in
   `android/app/build.gradle` from `keystore.properties`):

```bash
cd android
./gradlew bundleRelease     # android/app/build/outputs/bundle/release/app-release.aab
./gradlew assembleRelease   # android/app/build/outputs/apk/release/app-release.apk
```

4. Upload the `.aab` to the Play Console (a Play Console account, store listing,
   content rating and privacy policy URL are manual steps outside this project).

## Notes

- No APK/AAB is built in this repository — the Android SDK and Gradle are not
  available in the Lovable environment. Steps above must be run locally with
  Android Studio / JDK 17 installed.
- Debugging of the WebView is disabled for release (`webContentsDebuggingEnabled: false`).
- No secrets live in the Android project; Supabase uses the same publishable key
  as the web app, and all access stays behind existing RLS/auth rules.
